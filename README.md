# Studyond -- StartHack 2026

Welcome! This repository contains everything you need to work on the Studyond hackathon challenge.

## About Studyond

Studyond is a swiss startup that helps students and researchers to find topics, connect with professors, and manage their thesis journey efficiently. The goal of this hackathon is to develop an AI-powered solution that can automate or assist in the role-out process of finding a professor for thesis supervision.
